# 🌱 Benevo — Gestão de Doações para ONGs

> Plataforma para gerenciamento de doações, controle de estoque e distribuição de itens entre doadores e beneficiários.

Projeto acadêmico desenvolvido em equipe, conquistando o **🥈 2º lugar**.

## 🛠️ Tecnologias

| Tecnologia | Utilização |
|:--|:--|
| ☕ Java 17 | Desenvolvimento back-end |
| 🍃 Spring Boot | Construção da API REST |
| 🍃 MongoDB | Persistência de dados |
| 🔐 Spring Security | Segurança e autenticação |
| 🌐 HTML5, CSS3 e JavaScript | Interface web |
| 📦 Maven | Gerenciamento de dependências |

## 👨‍💻 Minha atuação

**Back-end Developer & Data Architect**

- Desenvolvimento de APIs REST com Java e Spring Boot.
- Implementação de regras de negócio para gerenciamento de doações.
